Research software

Computing the
lower spectral radius

  • MATLAB
  • Public source
  • GPL-3.0

How slowly can products of matrices grow? These routines implement algorithms for the lower spectral radius of families of real nonnegative matrices, including the standard and corrected adaptive methods from our research.

Explore the mathematics in the research explainer, or start with a MATLAB example that compares the methods and reports bounds on the original matrix scale.

Try it

A reproducible first example

Requires MATLAB with Optimization Toolbox for the default solver. The repository also supports an optional CVX solver.

Download corrected source · ZIPDownload starter · MATLAB
  1. Extract the source ZIP and put the starter script beside the repository’s MATLAB functions.
  2. Select that folder as MATLAB’s Current Folder, then run:
lower_spectral_radius_example

The starter compares standard S, adaptive A, and experimental eigenvector E. Results use floating-point arithmetic; the eigenvector variant has no general theoretical convergence guarantee. Source revision: 181d6b5.

Research code & verification

Certified lower exponents

Code and reproducibility material for my preprint on Euler discretizations of positive switched systems. The repository contains input matrices, complete numerical records, stored certificates, and independent Python and MATLAB verification scripts.

Exact rational checks verify the supplied continuous-time brackets. The manuscript explains which other numerical estimates remain floating point and which lower bounds lack independent replay witnesses; this distinction matters when interpreting the results.

Mac application · Working prototype

ArxivLens

A research inbox built around your interests. Follow arXiv subjects, keywords, and authors; save papers into collections, add notes, and export references as BibTeX.

For macOS 13 and later. Public release is in preparation; the project page shows the current interface and features.

Mac application · In development

TeXTint

A native LaTeX and Markdown editor I am developing for mathematical writing. TeXTint brings source files, document previews, and references into one customizable workspace.

  • Live PDF and Markdown previews, with navigation between LaTeX source and PDF
  • Project navigation, citation completion, and BibTeX tools
  • Customizable colour themes and editor appearance
  • Project health checks and research notes to help resume a draft

The current prototype targets Apple Silicon Macs running macOS 14 or later. LaTeX-to-PDF compilation uses a local TeX installation.
