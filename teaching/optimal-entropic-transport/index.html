Optimal
entropic transport.

These notes approach transport through probability and relative entropy. The reading thread runs from the likelihood of rare events to an optimisation problem for probability measures with prescribed endpoints.

Before you begin

A little background.

Review probability measures, integration, weak convergence, and basic optimal transport. Familiarity with conditional probability and Markov processes helps in the later material; convex analysis is useful for understanding entropy.

A first pass

Give every probability measure a role.

Before reading a proof, identify the reference measure, the competing measure, and the constraints. Keep that small glossary beside you as the notes move from a static coupling to a probability measure on paths. The PDF combines a typeset opening with scanned handwritten lectures.

This is my suggested reading route, rather than an official course syllabus.

Where to start

A route through the notes.

  1. Large deviations and entropy

    Start with the probabilistic motivation

    Read the opening large-deviation and Laplace-principle material for its main message: rare events can have a variational description. Then study relative entropy, keeping the reference measure explicit.

    Keep in mind Entropy is relative to another measure; changing the reference changes the problem.

  2. The Schrödinger problem

    Write down the constraints

    Compare the static and dynamic formulations. In the static problem, identify the endpoint coupling and its marginals; in the dynamic problem, identify the path measure and its endpoint distributions.

    Keep in mind A measure on pairs of endpoints and a measure on full paths are different objects.

  3. Connections with optimal transport

    Track the limiting problem

    In the small-parameter discussion, distinguish the entropy minimisation problem from the transport cost that emerges in the limit. Follow the stated mode of convergence rather than relying only on a formal limiting expression.

    Keep in mind A variational limit concerns minimisation problems, and requires more than a pointwise limit of formulas.

  4. Brownian and Markov viewpoints

    Return to the reference process

    Use the later Brownian-motion and Markov-measure material to revisit the dynamic formulation. Ask which properties belong to the reference process and which describe the optimising path measure.

    Keep in mind Keeping the reference law visible helps organise the conditional and time-dependent notation.

Read actively

Three questions to carry with you.

Try answering these in your own words. Open a prompt when you want a starting point.

Why does the reference measure matter?

Compare relative entropy with two different reference laws. Ask which events have zero reference probability and what that means for a competing measure with finite entropy.

What distinguishes the static and dynamic constraints?

Write an endpoint pair and then a whole path with those endpoints. The endpoints do not determine the intermediate trajectory; use this to separate the two admissible classes.

What should survive a small-parameter limit?

Identify the endpoint constraints and the limiting transport cost. Check separately what happens to admissible measures, objective values, and minimisers.
